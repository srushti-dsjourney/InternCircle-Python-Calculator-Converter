🚀 PYTHON CALCULATOR & UNIT CONVERTER

A simple and interactive command-line application developed using Python as part of my InternCircle Python Programming Internship.

📌 PROJECT OVERVIEW

This project combines a basic calculator, unit converter, and currency converter into one interactive Python application. It demonstrates fundamental programming concepts such as functions, loops, conditional statements, user input, and error handling.

✨ FEATURES

➕ Basic Calculator
• Addition
• Subtraction
• Multiplication
• Division

📏 Unit Converter
• Kilometers to Miles
• Miles to Kilometers
• Celsius to Fahrenheit
• Fahrenheit to Celsius

💱 Currency Converter
• INR to USD
• USD to INR

🛡️ Input validation and basic error handling

🔄 Interactive menu-driven interface

🛠️ TECHNOLOGIES USED

🐍 Python 3
💻 Command-Line Interface (CLI)
📚 Built-in Python functions and modules

▶️ HOW TO RUN

1️⃣ Download or clone this repository.

2️⃣ Open the project folder in VS Code or any Python-supported editor.

3️⃣ Run the following command:

python task1_calculator_converter.py
